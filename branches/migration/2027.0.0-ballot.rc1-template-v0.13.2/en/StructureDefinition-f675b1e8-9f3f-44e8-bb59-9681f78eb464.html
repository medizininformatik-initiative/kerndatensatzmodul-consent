Resource Profile: Profile - MI-I - Consent - Provenance

Official URL: https://www.medizininformatik-initiative.de/fhir/modul-consent/StructureDefinition/mii-pr-consent-provenance Version: 2027.0.0-ballot.rc1
Active as of 2023-05-09 Computable Name: MII_PR_Consent_Provenance

Dieses Profil beschreibt Herkunftsinformationen zu Einwilligungen in der Medizininformatik-Initiative.

Based on the recommendations of the AG Einwilligungsmanagement, the profile MIIConsentProvenance describes the provenance information of a consent document.

Only the differences to the base profile are explained below.

FHIR element Explanation
Provenance.entity.what If a document scan is to be attached, the referenced resource must be of the profile type DocumentReference, Must-support
Provenance.entity.signature.type If a base64-encoded signature is to be attached, the type of the signature must follow MII_VS_Consent_SignatureTypes, Must-support

Usages:

  • Examples for this Profile: Provenance/55219d12-6245-4de4-8b50-ddf6f16a789b
